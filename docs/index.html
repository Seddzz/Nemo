Overview / Quickstart

Quickstart

Get started with AnonShield — a zero-trust, $0 local anonymizer for French and English documents. Redact sensitive personal identifiable information (PII) before sending context to LLMs, then restore original values seamlessly.

Three ways to integrate AnonShield:
REST API
Full programmatic control for Python, Node.js, and web backends (`/anonymize` & `/restore`).
CLI Batch Tool
Command-line utility for shell scripts and batch document processing (`anon ./docs/*.pdf`).
MCP Agent SDK
Native Model Context Protocol tools for AI agents (Claude Desktop, Cursor, LangChain).
Zero Data Leakage Guarantee AnonShield runs 100% locally on CPU. By mounting your files as read-only (:ro) inside Docker, no text or credentials ever leave your infrastructure.
Interactive Swagger Documentation Once the container is running locally, visit http://localhost:8000/docs to explore live OpenAPI endpoint schemas. 
import requests

url = "http://localhost:8000/anonymize"
headers = {"X-API-Key": "your_secret_key"}

# 1. Anonymize document text
payload = {
    "text": "Contract between John Doe (john@example.com) and Acme Corp on 03/15/2024. IBAN: GB29NWBK60161331926819.",
    "reversible": True
}

response = requests.post(url, json=payload, headers=headers)
result = response.json()

print(result["redacted_text"])
# Output: "Contract between [PERSON_1] ([EMAIL_1]) and [ORG_1] on [DATE_1]. IBAN: [IBAN_1]."

print(result["mapping_id"])
# Output: "map_a98f12c"

Interfaces / REST API

                    
REST API Reference

                    

                        High-performance FastAPI endpoints running locally at http://localhost:8000.
                    

                


                
                

                    
                    
                    

                        

                            POST
                            /anonymize
                            Anonymize raw text or PDF upload
                        

                        

                            Accepts JSON {"text": "..."} or multipart PDF file upload. Extracts text, runs hybrid detectors, replaces PII with stable placeholders, and stores mapping in memory.
                        

                        

                            Headers: X-API-Key: <YOUR_SECRET_KEY>
                        

                    


                    
                    

                        

                            POST
                            /restore
                            Revert placeholders to original values
                        

                        

                            Accepts JSON {"text": "...", "mapping_id": "map_a98f12c"} and swaps placeholders back to original values.
                        

                    


                    
                    

                        

                            GET
                            /health
                            Container health check
                        

                        

                            Open endpoint (no auth required) used by Docker and monitoring services.
                        

                    


                

            



            
            

                

                    
Interfaces / CLI Batch Tool

                    
CLI Usage (`anon`)

                    

                        Built with Typer for batch operations, scripts, and folder processing.
                    

                


                

                    
# Process all PDFs in contracts folder

                    
$ anon ./contracts/*.pdf --out ./clean/ --mapping-out ./mappings/

                    

                        Processed 12 files [====================================] 100%

                        [SUCCESS] contract_1.pdf -> ./clean/contract_1.pdf (Entities: 4 PERSON, 2 IBAN)

                        [SUCCESS] contract_2.pdf -> ./clean/contract_2.pdf (Entities: 1 EMAIL, 1 PHONE)
                    

                

            



            
            

                

                    
Interfaces / Agent SDK

                    
MCP Server (Model Context Protocol)

                    

                        Exposes two native tools to AI agents: anonymize_document(path) and restore_text(text, mapping_id).
                    

                


                

                    

                        Add to your claude_desktop_config.json or Cursor settings:
                    

                    
{
  "mcpServers": {
    "anonshield": {
      "command": "docker",
      "args": [
        "run", "-i", "--rm",
        "-v", "/home/me/docs:/data:ro",
        "ghcr.io/seddzz/anonymizer",
        "python", "-m", "anonymizer.mcp"
      ]
    }
  }
}
